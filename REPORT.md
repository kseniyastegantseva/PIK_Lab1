# Лабораторная работа №1

## Тема

Основные конструкции языка Python.

## Цель работы

Изучить процедурный, объектно-ориентированный и функциональный подходы в Python.

## Постановка задачи

Разработать три консольные программы для решения биквадратного уравнения:

```text
A*x^4 + B*x^2 + C = 0
```

Программы должны получать коэффициенты с клавиатуры или из командной строки,
проверять корректность ввода, вычислять дискриминант и выводить действительные корни.

## Реализация

1. `procedural.py` использует функции.
2. `oop.py` использует класс `Equation`.
3. `functional.py` использует сопоставление с образцом `match-case`.

Во всех программах сначала решается квадратное уравнение относительно `y = x^2`.
Затем из неотрицательных значений `y` находятся действительные значения `x`.

## Пример выполнения

Команда:

```text
python procedural.py 1 -5 4
```

Результат:

```text
Дискриминант: 9.0
Действительные корни: [-2.0, -1.0, 1.0, 2.0]
```

Аналогично запускаются `oop.py` и `functional.py`.

## Вывод

Были изучены функции, классы, обработка исключений, аргументы командной строки
и конструкция сопоставления с образцом `match-case`.
